# S60 OBD

2017 Volvo S60 T3 icin OBD okuma araclari.

- `android/` - Android uygulamasi (ELM327 Bluetooth / WiFi): canli gosterge, tum OBD modullerinde ariza kodu tarama/silme, surus kaydi ve ozet.
- `volvo_obd.py` - ayni islevlerin bilgisayar (Python) surumu.
